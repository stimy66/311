# مطعم 311 — موقع الطلبات (نسخة محلية)

هذا المستودع يحتوي على نسخة صفحة واحدة (SPA) لواجهة طلبات التوصيل والـTakeaway لمطعم "مطعم 311".

الميزات:
- واجهة كاملة باللغة العربية وباتجاه RTL.
- تصميم داكن عصري مع لهجات أمبر.
- قائمة طعام مقسمة: البرغر، البيتزا، المشروبات.
- صور عالية الجودة من Unsplash لكل صنف.
- سلة تفاعلية مع حساب الأسعار حسب الحجم والكمية.
- إرسال الطلب عبر واتساب مع رسالة عربية منسقة.
- الدفع: الدفع نقداً عند الاستلام فقط.

الملفات المهمة:
- `index.html` — الصفحة الرئيسية (HTML + Tailwind CDN)
- `script.js` — منطق السلة وبناء رسالة الواتساب
- `manifest.json` — ملف ميتاداتا لتشغيل كتطبيق (PWA) إن رغبت

كيفية الاستخدام:
1. ضع رقم واتساب المطعم بالصيغة الدولية في `script.js` في المتغير `restaurantPhone`.
2. افتح `index.html` في المتصفح.
3. أضف عناصر إلى السلة، ثم املأ بيانات التوصيل واضغط "تأكيد الطلب عبر الواتساب".

ملاحظات أمان وخصوصية:
- لا يتم إرسال أي بيانات إلى خادم — كل شيء يتم محلياً وفتح واتساب لتحويل الطلب.
- الصور مستضافة في Unsplash (CDN). تأكد من الامتثال لرخصة الاستخدام إن أردت نسخة تجارية.

إذا رغبت بتحويل المشروع إلى React + Vite أو نشره على استضافة ثابتة (Netlify / Vercel)، قُم بإخباري وسأعد الملفات اللازمة.
